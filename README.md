# X to Nostr Mirror: User Guide

This repository has the user guide for **X to Nostr Mirror**, a desktop app that copies posts from X (Twitter)
accounts to Nostr accounts from your own computer. It has previews, original-date (backdated) notes,
duplicate protection, multiple profiles and schedules.

📖 **[Read the user guide](docs/USER_GUIDE.md)**

It covers installing and upgrading, the X developer API token, Nostr keys, fetching by date range,
publishing progress, status numbers, duplicate protection, schedules (including the sleep/offline caveat)
and key security.

This repository contains documentation only. It has no app source code or downloads.
