    About X to Nostr Mirror

    X to Nostr Mirror copies posts from X (Twitter) accounts to Nostr accounts from your own computer. It reads posts with your own X developer API token, lets you preview them, publishes them as signed Nostr notes (optionally with their original dates), remembers what was already posted so nothing is duplicated, and can run on a schedule. Your keys stay encrypted in your Mac's Keychain. No tracking, no cloud service.

    Settings
    
    
    X API access
    
      
    Reading posts requires your own X developer app Bearer token (developer.x.com). Your X username/password will not work. Access tiers and pricing are set by X; check the developer portal. The token is encrypted with your OS keychain and never shown again.
    
      
    
      
    
    
    Background scheduling (macOS)
    
      
    While this app is open, enabled schedules run automatically. To run them when the app is closed, install a LaunchAgent. Nothing runs while the Mac is asleep, off, or offline; missed runs are caught up on the next opportunity.
    
      
    
    
    Profiles file
    Export/import profile settings without any keys, tokens or history. Imported profiles start disabled.

    Save selected posts & media to this computer (optional)
        
    Separate from publishing. Nostr notes always link to the pictures/videos on X's servers; nothing is uploaded anywhere. This only saves copies (post data as JSON, plus picture/video files) into a folder you choose. Your keys, token and history stay in the app's protected data folder and are never exported.
